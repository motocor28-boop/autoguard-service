# Nexo Secure — APK de prueba Android v0.2

Aplicación Android de demostración para probar la interfaz de Nexo Secure en un teléfono real.

## Credenciales de demostración

- Teléfono: `9 1111 1111`
- PIN: `246810`

## Alcance de esta compilación

- Instalable en Android 8.0 o posterior.
- Interfaz local integrada en la APK.
- Mensajes de demostración.
- Grabación local de radio PTT cuando se autoriza el micrófono.
- Llamadas simuladas.
- Identidad criptográfica local.

## Limitación esencial

Esta APK todavía **no comunica dos teléfonos reales**. No utiliza servidor, OTP real, cifrado de extremo a extremo entre dispositivos, WebRTC ni notificaciones. No debe emplearse para información sensible ni para emergencias.

## Instalación

1. Copiar la APK al teléfono Android.
2. Abrirla desde Archivos o Descargas.
3. Autorizar temporalmente la instalación desde esa fuente.
4. Instalar y abrir `Nexo Secure Demo`.
5. Conceder permiso de micrófono al probar la radio PTT.
